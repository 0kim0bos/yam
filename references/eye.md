# Eye

`eye` is visual inspection for UI/UX quality.

Inputs:

- Screenshot.
- URL.
- Current local app screen.
- Reference image.

Review dimensions:

- Direction fit.
- Visual hierarchy.
- CTA clarity.
- Spacing and alignment.
- Contrast.
- Responsive behavior.
- Empty, loading, error, disabled states.
- Interaction affordance.

Output:

- P0: blocker.
- P1: major issue.
- P2: noticeable quality issue.
- P3: polish.
- Safe fix suggestions.
